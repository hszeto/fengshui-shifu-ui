# ⛩️ FengShui-Shifu UI (`fengshui-shifu-ui`)

Cross-platform React Native Web (Expo) frontend for **FengShui-Shifu (风水师傅)** — AI Spatial Feng Shui & BaZi Fortune Telling Platform.

---

## 🚀 Quick Start (Local Development)

```bash
# Install dependencies
npm install

# Start Expo Web App
npm run web
```

Open `http://localhost:8081` to view the web application.

---

## 📱 Mobile Preview (iOS / Android)
```bash
# Start Expo Metro Bundler for Mobile
npx expo start
```
Scan the QR code with the **Expo Go** app on your iOS or Android phone!

---

## 📡 API Connection
The frontend connects to `fengshui-shifu-api` at `http://localhost:3000/api/v1`.
Set `EXPO_PUBLIC_API_URL` environment variable to override for production staging.
